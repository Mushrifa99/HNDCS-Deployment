# Mushrifa — Neon Blue Portfolio

A responsive one-page portfolio built with Next.js, TypeScript, Framer Motion and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal in VS Code and run:

```bash
npm install
npm run dev
```

4. Visit http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Personalize

Update the name, email, social links, skills, services and project details in `src/app/page.tsx`.
Replace sample project links with your real deployed project URLs before publishing.
